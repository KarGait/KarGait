## Current work

### PollCentral — national polling platform for Kenya's 2027 general election
**Live: [pollcentral.net](https://pollcentral.net)**

- Lambda-style aggregation in PostgreSQL: triggers keep live per-ward totals for the open polling wave, and a cron job rebuilds each closed wave from the raw votes into cache tables.
- Parsed IEBC voter-statistics PDFs into 47 counties, 290 constituencies, 1,450 wards and 27,273 registration centres.
- Leaflet maps coloured by leading party, and win probabilities from a Dirichlet posterior.
- Mobile-first, in English and Swahili.

### OSCE Training — clinical examiner training & calibration platform
- Trainee examiners score recorded exam stations against reference examiners' marks.
- Standard setting by Borderline Regression, Contrasting Groups and Borderline Group.
- Cronbach's alpha, and a mixed-effects model (lme4) of examiner severity.

Source code for both is available to walk through on request.
